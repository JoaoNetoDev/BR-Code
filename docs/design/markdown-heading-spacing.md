# Espaçamento entre títulos Markdown

A renderização dos títulos Markdown está no componente `MessageResponse`, em `packages/ui/src/components/ai-elements/message.tsx`.

- De `h1` a `h6`, o espaçamento superior usa uniformemente `mt-6`.
- De `h1` a `h6`, o espaçamento inferior usa uniformemente `mb-4`, mantendo uma separação de leitura mais clara entre o título e o texto seguinte.
