## Razões para Remover / Manter Nesta Rodada

- Removidos os branches de leitura/escrita dupla do estado intermediário no Markdown e a conversão de Provider em memória de todo o profile; removido o parser genérico antigo do Host, separando o codec Markdown oficial do JSON schema.
- Mantida a ModelSelection estruturada interna/de protocolo; o novo map do JSON embutido não é estado intermediário de Markdown.
- Mantida a projeção de hydration da exibição do histórico de mensagens e o importer de dados realmente antigos; eles não podem voltar a ser fonte alternativa da seleção atual.
- Se o formato antigo já foi publicado é julgado pelos pontos de escrita reais do staging: o entry de thoughtLevel da Session e o Bot v2 existem de fato; não se apaga em massa apenas porque o campo parece antigo.
- Os arquivos só são alterados no diretório do usuário; sem marcação global de "migração concluída" e sem omitir arquivos antigos adicionados depois; os limites de lock de arquivo, comparação de texto original, permissões e symlinks ficam por conta da entrada Node compartilhada. Uma requisição comum não chama migração e não troca Provider sorrateiramente.
