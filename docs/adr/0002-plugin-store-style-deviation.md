# A Página da Loja de Plugins Desvia Intencionalmente do Estilo Contido de DESIGN.md

O design system do repositório (DESIGN.md) exige evitar "spacing estilo marketing, gradientes brincativos e preenchimentos de marca Bright em superfície total". O redesign da loja de plugins de 2026-07 é uma decisão de produto explícita: adotar o visual e as interações de uma loja expositiva (títulos grandes de nível display, espaçamento generoso, banner hero com gradiente, cápsulas de prompts de exemplo). Esse desvio **limita-se às interfaces relacionadas à loja de plugins** (página de listagem, página de detalhes, visão de instalados gerenciados) e não constitui precedente para outras páginas de configuração ou para a UI global; a página da loja ainda deve usar os tokens semânticos existentes para implementar os temas claro/escuro e a adaptação a chinês e inglês. Se no futuro o design system entrar em conflito com o estilo da loja, esta decisão prevalece — não "corrija de passagem" o espaçamento e os gradientes da página da loja.
